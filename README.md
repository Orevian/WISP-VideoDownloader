# ⚡ Elite Video Downloader

**Fast. Simple. Powerful.**

A fast and modern video downloader that makes downloading content simple.

You don't necessarily need a link. **Search for a video by name directly inside the application**, select the result, choose your preferred format and quality, and download it.

---

## ✨ Features

* 🔎 **Search by Name** — Search for videos directly inside the application.
* 🔗 **URL Support** — Paste a supported video URL when you already have one.
* ⚡ **Fast Downloads** — Designed for speed and performance.
* 🎥 **Video Downloads** — Download supported videos in available formats and qualities.
* 🎵 **Audio Downloads** — Download audio where supported.
* 🖥️ **Modern Interface** — Clean, simple and easy to use.
* 📦 **Lightweight** — Designed to stay fast without unnecessary background processes.
* 🔐 **No Account Required** — No Google or YouTube password is required.

---

## 🚀 How It Works

### 1. Search

Enter the name of the video you want to find.

```text
Search: Interstellar Main Theme
```

The application searches for matching results and displays them directly inside the interface.

### 2. Select

Choose the video you want to download.

### 3. Download

Select the available format and quality, then start the download.

You can also paste a supported URL directly into the application.
